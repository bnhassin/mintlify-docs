This guide takes you from zero to a working streaming call through Vercel AI Gateway, the model-provider boundary used by BnhassinAgent. For the full setup and production recommendations, see [AI Gateway](/ai-gateway).

## Prerequisites

Before you begin, you must have:

- Node.js and npm installed
- A Vercel account
- A Vercel AI Gateway API key

## Get started

<Steps>
  <Step title="Install the Vercel CLI">
    ```bash
    npm i -g vercel
    vercel login
    ```
  </Step>
  <Step title="Create the project">
    ```bash
    mkdir bnhassinagent-ai-gateway
    cd bnhassinagent-ai-gateway
    npm init -y
    npm install ai dotenv
    npm install -D @types/node tsx typescript
    ```
  </Step>
  <Step title="Add your API key">
    Create a `.env` file and never commit it to Git:

    ```dotenv
    AI_GATEWAY_API_KEY=your_vercel_ai_gateway_key
    ```
  </Step>
  <Step title="Run the smoke test">
    Create `index.ts` as described in [AI Gateway](/ai-gateway), then run:

    ```bash
    npx tsx index.ts
    ```

    A successful run streams text to the terminal, then prints token usage and the finish reason.
  </Step>
</Steps>
